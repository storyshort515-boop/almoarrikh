# منصة المؤرخ

منصة تعليمية للأستاذ سعيد إسماعيل (المؤرخ) لتاريخ الثانوي العام: أولى ثانوي، تانية بكالوريا، تالتة ثانوي.

بدون أي مكتبات خارجية: Node.js 22.5 أو أحدث فقط (قاعدة البيانات SQLite مدمجة في Node).

## التشغيل

```bash
cd almoarrikh
ADMIN_PHONE=01012345678 ADMIN_PASSWORD='كلمة-سر-قوية' npm start
```

افتح http://localhost:3000

أول مرة بيتعمل حساب الأدمن (المدرس) تلقائيًا. لو ملحقتش ADMIN_PASSWORD بتتولد كلمة سر عشوائية وبتتطبع في الشاشة مرة واحدة.

بيانات تجريبية اختيارية (كورسات وأسئلة وطالب تجريبي): `npm run seed:demo`

اختبار الـ API الشامل: `npm test`

## الإعدادات (متغيرات بيئة)

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `PORT` | المنفذ | 3000 |
| `ADMIN_PHONE` / `ADMIN_PASSWORD` | حساب الأدمن عند أول تشغيل | 01000000000 / عشوائي |
| `DATA_DIR` | مكان قاعدة البيانات | `./data` |
| `MAX_DEVICES` | أقصى عدد أجهزة مسجلة بنفس الحساب للطالب | 2 |
| `COOKIE_SECURE=1` | فعّله لما الموقع يشتغل على HTTPS | - |
| `TRUST_PROXY=1` | لو وراء Nginx/Cloudflare عشان يقرأ IP الحقيقي | - |

## المميزات

الطالب: تسجيل بالموبايل، تصفح الكورسات حسب الصف، تفعيل كود الاشتراك، مشاهدة المحاضرات (علامة مائية باسم الطالب ورقمه)، تحميل المذكرات، متابعة التقدم، اختبارات بمؤقت وتصحيح فوري وشرح الإجابات.

المدرس (لوحة التحكم `/#/admin`): إحصائيات، إدارة الكورسات والمحاضرات وترتيبها، محرر الاختبارات (مع لصق أسئلة دفعة واحدة)، توليد أكواد الاشتراك وتحميلها CSV، إدارة الطلاب (بحث، إيقاف، اشتراك يدوي، تغيير كلمة المرور، إخراج من الأجهزة)، الإعلانات، وإعدادات المنصة (الاسم، النبذة، الصورة، روابط التواصل).

## الأمان المطبّق

تشفير كلمات المرور بـ scrypt، جلسات في HttpOnly cookie، حماية CSRF، حد لمحاولات الدخول والتسجيل وتفعيل الأكواد، حماية الفيديوهات (الرابط لا يُرسل إلا للمشترك)، CSP وباقي headers، وتهريب (escape) كل نص معروض ضد XSS.

## قبل ما تفتحها للطلاب فعليًا

1. **الاستضافة والدومين**: شغّلها على VPS (أو Railway/Render مع volume للقاعدة) وراء Nginx أو Caddy مع HTTPS، وفعّل `COOKIE_SECURE=1`.
2. **استضافة الفيديو**: المنصة بتعرض فيديوهات من يوتيوب (Unlisted) أو Vimeo أو Bunny Stream أو Google Drive أو mp4. للحماية الحقيقية من التحميل والمشاركة استخدم Bunny Stream أو Vimeo مع تقييد الدومين بدومين المنصة. العلامة المائية بتردع المشاركة لكنها مش بتمنع تسجيل الشاشة.
3. **الدفع الإلكتروني**: غير مربوط. الاشتراك حاليًا بالأكواد (الأشهر في السوق المصري) أو إضافة يدوية من لوحة التحكم. ربط Paymob أو Fawry محتاج حساب تاجر وبياناته.
4. **النسخ الاحتياطي**: انسخ ملف `data/almoarrikh.db` بشكل دوري.
5. **المحتوى**: أضف الكورسات والمحاضرات الحقيقية من لوحة التحكم، وارفع صورة الأستاذ وروابط التواصل من الإعدادات.

## النشر على Railway

1. ارفع فولدر المشروع على مستودع GitHub خاص.
2. في Railway: New Project ثم Deploy from GitHub repo واختار المستودع (هيستخدم `Dockerfile` تلقائيًا).
3. من تبويب Variables أضف: `ADMIN_PHONE` و `ADMIN_PASSWORD`.
4. من تبويب Settings ثم Volumes أضف Volume واجعل Mount Path هو `/data` (بدونه القاعدة بتتمسح مع كل نشر).
5. من Settings ثم Networking اضغط Generate Domain وافتح الرابط من الموبايل.
